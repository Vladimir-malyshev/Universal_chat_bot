Роль: Senior AI/Backend Architect

Контекст: Наш Telegram-бот (Оркестратор + LLM) уже отлично работает с текстовыми сообщениями. Теперь нужно добавить поддержку голосовых сообщений (Speech-to-Text), чтобы пользователи могли наговаривать запросы аудио.

Задача: Реализовать пайплайн распознавания голосовых сообщений из Telegram с помощью акустической модели Сбера GigaAM v3.

Требования к реализации (Пайплайн):

    Telegram Adapter (telegram_adapter.py):

        Добавить обработку сообщений типа voice.

        Реализовать скачивание аудиофайла через методы Telegram API (getFile и последующая загрузка по ссылке).

    Конвертация аудио (Аудио-препроцессинг):

        Telegram присылает голосовые в формате OGG (кодек Opus).

        GigaAM требует на вход WAV, 16000 Hz, mono.

        Напиши модуль/утилиту для асинхронной конвертации скачанного OGG в нужный WAV формат (можно использовать ffmpeg через subprocess или библиотеку pydub).

        Важно: Обеспечь правильное удаление временных аудиофайлов (OGG и WAV) после распознавания, чтобы не засорять диск сервера.

    Интеграция модели GigaAM (stt_service.py или аналогичный модуль):

        Использовать официальный репозиторий: https://github.com/salute-developers/GigaAM

        Целевая модель: Использовать самую новую версию v3. В частности, нужна модель, поддерживающая пунктуацию и нормализацию (например, v3_e2e_ctc или актуальная e2e/RNNT модель третьего поколения из репозитория).

        Написать класс/функцию инициализации модели при старте приложения (чтобы модель загружалась в память один раз, а не при каждом запросе).

        Реализовать метод транскрибации transcribe_audio(file_path), который возвращает готовый текст с правильной пунктуацией.

    Маршрутизация текста:

        Полученный из аудио текст должен передаваться в существующий пайплайн обработки (в Оркестратор/LLM) ровно так же, как если бы пользователь ввел этот текст руками.

        Опционально: можно отправлять пользователю промежуточное сообщение в Telegram: "🎤 Распознал голосовое: [тут текст]. Думаю над ответом...", чтобы он понимал, что бот его правильно услышал.

Ожидаемый результат:

    Код для загрузки и инициализации GigaAM v3.

    Обновленный Telegram-адаптер.

    Утилита для конвертации аудио.

    Проверка пайплайна на отсутствие утечек памяти (удаление временных файлов).
