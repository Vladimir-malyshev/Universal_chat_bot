ТЗ для агента: Внедрение Web Search (Tool Calling)

Роль: Senior AI Backend Developer

Контекст задачи: Наш бот (Морфеус) уже умеет общаться текстом, слушать аудио (GigaAM) и видеть фото (Vision). Теперь нам нужно дать LLM (которая крутится в Chutes) возможность самостоятельно искать свежую информацию в интернете (цены, конкуренты, новости), используя Tool Calling.
Для экономии платных лимитов API мы будем использовать бесплатную библиотеку duckduckgo-search.

План реализации:

Шаг 1. Создание инструмента поиска (tools.py или аналогичный модуль):

    Добавь в зависимости проекта: pip install duckduckgo-search

    Напиши асинхронную функцию search_web(query: str, max_results: int = 3) -> str.

    Внутри используй DDGS().text(query, max_results=max_results). Функция должна возвращать компактную строку (сборник сниппетов и ссылок), чтобы не переполнять контекст LLM.

Шаг 2. Описание схемы инструмента (Tool Schema):
Подготовь JSON-схему инструмента в формате OpenAI (стандарт для большинства API):
Python

search_tool_schema = {
    "type": "function",
    "function": {
        "name": "search_web",
        "description": "Поиск в интернете. Используй ТОЛЬКО для запросов о текущих ценах, новостях, конкурентах или событиях 2025-2026 годов. Не используй для общих знаний.",
        "parameters": {
            "type": "object",
            "properties": {
                "query": {"type": "string", "description": "Точный поисковый запрос (например, 'курс биткоина сегодня' или 'цены на удобрения 2026')"}
            },
            "required": ["query"]
        }
    }
}

Шаг 3. Модификация Оркестратора (Реализация Double-Hop):
Обнови логику отправки сообщений в LLM (orchestrator.py):

    В первый запрос к LLM передавай список доступных инструментов: tools=[search_tool_schema].

    Проверка ответа: Если LLM возвращает tool_calls (или finish_reason == "tool_calls"):

        Извлеки имя функции и аргументы (распарси JSON и достань query).

        Вызови нашу python-функцию await search_web(query).

        Добавь результат выполнения в историю сообщений (в формате, который требует API Chutes, обычно это сообщение с role: "tool" и tool_call_id).

        Сделай второй вызов LLM, передав ей обновленную историю (с результатами поиска).

    Если tool_calls нет — просто верни текстовый ответ пользователю.

Шаг 4. Обновление System Prompt:
Добавь в системную инструкцию Морфеуса жесткое правило: "Ты можешь использовать инструмент search_web, но делай это экономно. Только если клиент спрашивает конкретные свежие данные. Получив данные из поиска, вплетай их в свой продающий ответ органично."

Ожидаемый результат: Бот не падает при запросе свежих данных, а делает паузу, гуглит через твой сервер и выдает ответ с актуальной информацией.
